# Data Cleaning & Visualization Project

## Overview
This project performs data cleaning and visualization on the Titanic dataset using Python.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab

## Features
- Missing value handling
- Duplicate removal
- Data visualization
- Correlation heatmap
- Data preprocessing

Titanic Dataset
